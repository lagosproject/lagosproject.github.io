🧬 The Clinical Command Center

We build unified, clinical-grade bioinformatics software systems. Our flagship workflow combines PS Analyzer and Bio-Engine into a high-performance Sanger sequence variant interpretation ecosystem.

PS Analyzer provides the secure, local-first Angular/Tauri interface for clinical variant visualization, while Bio-Engine operates as the asynchronous Python backend, handling heavy alignments with Tracy and functional predictions with VEP.

🧠 The Intelligent Utility Wing

Translating machine learning research into specialized utilities. We frame our projects as deep pipelines optimized for performance and domain specialists.

🎵 Latin Music Genre Classification

A comprehensive deep learning workflow leveraging **CLAP music embeddings** combined with traditional acoustic descriptors (MFCCs, BPM). Tracks are evaluated across multi-model stack configurations to classify genres (Reggaeton, Bachata, Salsa, Merengue).

📸 ImageLabelIA — Tailored for Photographers

An AI-driven asset cataloging tool utilizing **Vision Transformers (ViT)** and **DEtection TRansformer (DETR)** to generate high-fidelity tags and zero-shot object detections, streamlining heavy photography workflows.
